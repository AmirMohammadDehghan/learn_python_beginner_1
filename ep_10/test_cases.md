# سناریوهای بررسی پروژه

هر سناریو را در اجرای تازه شروع کنید، مگر آنکه ادامهٔ سناریوی قبلی ذکر شده باشد. پس از پیام خطا در ثبت هزینه، برنامه به منوی اصلی برمی‌گردد؛ برای تلاش دوباره گزینهٔ ۱ را انتخاب کنید.

| سناریو | ورودی یا اقدام | نتیجهٔ مورد انتظار |
| --- | --- | --- |
| بودجهٔ نامعتبر | خالی، `abc`، `-10`، `1.5`، `1,000`، ده رقم | پیام خطا و درخواست دوبارهٔ بودجه |
| بودجهٔ صفر | `0` | رد ورودی و درخواست دوباره |
| رقم فارسی | بودجه `۱۰۰۰`، گزینه `۳` | بودجهٔ ۱۰۰۰، مجموع صفر، باقی‌ماندهٔ ۱۰۰۰ |
| گزینهٔ نامعتبر | `x`، `9`، `12`، `²` | پیام خطا و ادامهٔ منو |
| فهرست خالی | بودجهٔ معتبر و گزینهٔ ۲ | پیام «هنوز هزینه‌ای ثبت نشده است» |
| گزارش خالی | گزینهٔ ۳ پیش از ثبت | مجموع صفر، صفر دستهٔ استفاده‌شده، جمع هر دسته صفر |
| عنوان خالی | گزینهٔ ۱ و چند فاصله | عدم ثبت هزینه |
| مبلغ نامعتبر | عنوان معتبر و مبلغ خالی، منفی، اعشاری، متن یا بیش از ۹ رقم | عدم ثبت و بازگشت به منو |
| مبلغ صفر | عنوان معتبر و `0` | عدم ثبت |
| دستهٔ نامعتبر | هزینهٔ معتبر و دستهٔ `0`، `5` یا متن | عدم ثبت |
| سناریوی اصلی | ورودی‌های `codes_ep10/demo_input.txt` | گزارش اول: ۴۰۰۰۰۰، باقی‌ماندهٔ ۶۰۰۰۰۰؛ پس از حذف: ۲۵۰۰۰۰ و ۷۵۰۰۰۰ |
| شناسه پس از حذف | ادامهٔ سناریوی اصلی، ثبت چهارم | شناسهٔ ۴؛ شناسهٔ ۲ دوباره استفاده نمی‌شود |
| حذف شناسهٔ غایب | گزینهٔ ۴ و شناسهٔ ۹۹ | پیام پیدا نشد، بدون تغییر گزارش |
| شناسهٔ صفر | گزینهٔ ۴ و `0` | پیام شناسه باید بزرگ‌تر از صفر باشد |
| حذف آخرین هزینهٔ یک دسته | یک هزینه از دستهٔ خوراک ثبت و حذف کنید | جمع خوراک صفر و تعداد دسته‌های استفاده‌شده کم شود |
| مصرف دقیق بودجه | بودجهٔ ۱۰۰، هزینهٔ ۱۰۰ | باقی‌مانده صفر و پیام مصرف دقیق |
| عبور از بودجه | بودجهٔ ۱۰۰، هزینهٔ ۱۵۰ | باقی‌ماندهٔ منفی ۵۰ و هشدار ۵۰ تومان |
| هزینه‌های هم‌دسته | بودجهٔ ۱۰۰۰، هزینه‌های خوراک ۱۰۰ و ۲۰۰ | مجموع ۳۰۰، جمع خوراک ۳۰۰، یک دستهٔ استفاده‌شده |
| گزارش تکراری | دو بار گزارش بگیرید | نتیجه ثابت باشد و دوباره جمع نشود |
| خروج و اجرای دوباره | گزینهٔ صفر، سپس اجرای تازه | فهرست خالی؛ این نسخه ذخیرهٔ دائمی ندارد |

مبالغ جدول به تومان‌اند. هدف از آزمایش، مقایسهٔ نتیجه با محاسبهٔ دستی و توضیح دلیل رفتار برنامه است.
