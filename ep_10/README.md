# جلسهٔ 10: پروژهٔ پایانی

دفتر هزینه و کنترل بودجه

- ارائهٔ پاورپوینت در نسخهٔ محلی دوره موجود است و در این مخزن منتشر نمی‌شود.
- [جزوه و راهنمای کامل جلسه](lesson-guide.html)
- کدها: `codes_ep10/`

این جلسه مطابق ۱۳ بخش زیر تنظیم شده است. هر بخش ممکن است چند اسلاید داشته باشد.

1. **عنوان جلسه**: دفتر هزینه و کنترل بودجه
2. **اهداف یادگیری**: اهداف یادگیری
3. **مرور جلسه قبل**: مرور Dictionary در پروژه
4. **آموزش مبحث اول**: مسئلهٔ پروژه؛ قرارداد ورودی و خروجی؛ نقشهٔ داده‌ها؛ منوی برنامه؛ ساخت مرحله‌ای
5. **مثال مبحث اول**: مثال اول: بررسی مبلغ؛ مثال اول: ثبت یک رکورد؛ مثال اول: نمایش هزینه‌ها
6. **آموزش مبحث دوم**: گزارش مجموع و باقی‌مانده؛ گزارش دسته‌ها؛ نقش Set در گزارش؛ حذف با شناسه؛ حالت‌های بودجه
7. **مثال مبحث دوم**: مثال دوم: اجرای یک سناریوی کامل؛ مثال دوم: بررسی نتیجهٔ حذف
8. **نکات مهم**: نکات مهم پروژه؛ آموخته‌های دوره در یک برنامه
9. **خطاهای رایج**: خطاهای رایج: ورودی و رکورد؛ خطاهای رایج: گزارش و حذف
10. **تمرین کلاسی**: تمرین کلاسی: ساخت پروژه؛ تمرین کلاسی: سناریوهای پذیرش
11. **کوییز کوتاه**: کوییز کوتاه پروژه
12. **تمرین منزل**: تمرین منزل و تحویل پروژه
13. **جمع‌بندی**: جمع‌بندی و ادامهٔ مسیر

## اجرا

Python 3 لازم است. نصب کتابخانهٔ اضافی لازم نیست.

```sh
cd ep_10/codes_ep10
python budget_tracker.py
```

کد را در ترمینال اجرا کنید. فایل‌های تمرین را پیش از دیدن پاسخ پیشنهادی تکمیل کنید.

اطلاعات پروژه پس از خروج از برنامه ذخیره نمی‌شوند. مبالغ صحیح مثبت و بر حسب تومان‌اند.
