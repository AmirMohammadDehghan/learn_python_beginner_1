1. عنوان جلسه

Dictionary

  • جلسهٔ نهم

2. اهداف یادگیری

اهداف یادگیری

  • ساخت دیکشنری و انتخاب کلید مناسب برای هر داده
  • خواندن، تغییر، افزودن و حذف اعضا بدون خطای قابل پیشگیری
  • پیمایش و کپی داده‌ها و ساخت چند رکورد مرتبط

در پایان، هنرجو باید بتواند موجودی یک فروشگاه را با Dictionary مدیریت کند و تفاوت کلید، مقدار و اندیس را توضیح دهد.

3. مرور جلسه قبل

مرور Tuple و Set

  • Tuple ترتیب دارد و اعضای آن مستقیماً تغییر نمی‌کنند.
  • Set برای اعضای یکتا و بررسی عضویت مناسب است.
  • برای اتصال نام کالا به موجودی آن، به رابطهٔ کلید و مقدار نیاز داریم.

پرسش شروع: چرا یک Set برای نگهداری نام دانشجو همراه با نمرهٔ او کافی نیست؟ پاسخ: Set این رابطهٔ نام‌دار را نمایش نمی‌دهد. Dictionary نام یا شناسه را به مقدار مرتبط می‌کند.

4. آموزش مبحث اول

ساختار Dictionary

  • هر عضو از یک کلید و یک مقدار تشکیل می‌شود.
  • نام کلید معنی داده را مشخص می‌کند. مقدار می‌تواند عدد، متن یا ساختار دیگری باشد.
student = {
    "name": "Sara",
    "age": 20,
    "active": True,
}
print(student["name"])  # Sara

آکولاد ابتدا و انتها، دونقطه میان کلید و مقدار، و ویرگول میان اعضا را روی کد مشخص کنید. نام کلید و مقدار متنی هر دو داخل کوتیشن‌اند.

انتخاب کلید

  • برای شروع، از کلیدهای متنی یا عددی روشن و ثابت استفاده کنید.
  • کلید تکراری عضو تازه نمی‌سازد و مقدار قبلی را جایگزین می‌کند.
settings = {"theme": "light", "theme": "dark"}
print(settings)  # {'theme': 'dark'}
print(len(settings))  # 1

کلیدها باید hashable باشند. در سطح این دوره، رشته و عدد انتخاب‌های ساده‌اند. List و Dictionary کلید معتبر نیستند. مقادیر می‌توانند تکراری باشند. حساسیت حروف در name و Name را یادآوری کنید.

دسترسی امن به داده

  • براکت برای کلیدی است که از وجود آن مطمئن هستیم.
  • get برای کلید احتمالی، مقدار پیش‌فرض برمی‌گرداند.
student = {"name": "Sara"}
print(student["name"])
print(student.get("city", "Unknown"))
print("city" in student)  # False

student["city"] در این مثال KeyError می‌دهد. اگر پیش‌فرض get را ننویسیم و کلید موجود نباشد، None برمی‌گردد. وجود کلید را با in بررسی می‌کنیم، چون None ممکن است خودش مقدار یک کلید باشد.

تغییر و افزودن عضو

  • انتساب به کلید موجود، مقدار را تغییر می‌دهد.
  • انتساب به کلید جدید، عضو اضافه می‌کند. update چند مورد را اعمال می‌کند.
student = {"name": "Sara", "age": 20}
student["age"] = 21
student["city"] = "Tehran"
student.update({"age": 22, "active": True})
print(student["age"])  # 22

update دیکشنری اصلی را تغییر می‌دهد و None برمی‌گرداند. نتیجهٔ آن را دوباره به student نسبت ندهید. از هنرجو بپرسید کدام خط عضو جدید ساخته است.

حذف عضو

  • pop عضو را حذف می‌کند و مقدار آن را برمی‌گرداند.
  • del کلید را حذف می‌کند. clear همهٔ اعضا را خالی می‌کند.
student = {"name": "Sara", "city": "Tehran"}
city = student.pop("city")
print(city)  # Tehran
print(student.pop("phone", "Not found"))
del student["name"]
student.clear()
print(student)  # {}

del روی کلید غایب و pop بدون مقدار پیش‌فرض، KeyError می‌دهند. clear خود متغیر را حذف نمی‌کند. popitem آخرین عضو اضافه‌شده را حذف می‌کند اما برای تمرین اصلی به آن نیاز نداریم.

5. مثال مبحث اول

مثال اول: پروندهٔ دانشجو

  • نام و سن ثبت شده‌اند. شهر را اضافه می‌کنیم و وضعیت دانشجو را می‌خوانیم.
student = {"name": "Sara", "age": 20}
student["city"] = "Tehran"
student["age"] += 1
print(student["name"], student["age"])
print(student.get("active", False))

پیش از اجرا خروجی را پیش‌بینی کنید. خط age از عملگر انتسابی جلسه چهارم استفاده می‌کند.

پاسخ و توضیح

خروجی دو خط آخر: Sara 21 و سپس False. get کلید active را به دیکشنری اضافه نمی‌کند.

مثال اول: حذف اطلاعات اختیاری

  • حذف اطلاعات اختیاری باید برای کلید غایب هم قابل پیش‌بینی باشد.
student = {"name": "Sara", "city": "Tehran"}
removed = student.pop("city", "Unknown")
print(removed)
print(student.get("city", "Unknown"))
print(len(student))
پاسخ و توضیح

Tehran، سپس Unknown و سپس 1. فقط name باقی می‌ماند.

6. آموزش مبحث دوم

پیمایش کلیدها

  • حلقهٔ مستقیم روی دیکشنری، کلیدها را به ترتیب درج می‌دهد.
  • با هر کلید می‌توان مقدار همان عضو را خواند.
scores = {"Python": 18, "Math": 16}
for subject in scores:
    print(subject, scores[subject])

ترتیب درج در Python 3.7 به بعد تضمین شده است. این ویژگی به معنی دسترسی با اندیس صفر و یک نیست. scores[0] به دنبال کلید عددی صفر می‌گردد.

Keys، Values و Items

  • keys کلیدها، values مقدارها و items زوج کلید و مقدار را در اختیار می‌گذارند.
  • در حلقهٔ items، دو متغیر هر زوج را دریافت می‌کنند.
scores = {"Python": 18, "Math": 16}
print(list(scores.keys()))
print(list(scores.values()))
for subject, score in scores.items():
    print(subject, score)

خروجی این متدها نما است و تغییرات بعدی دیکشنری را منعکس می‌کند. list یک عکس لحظه‌ای از آن می‌سازد. بازکردن زوج‌ها به مبحث Unpacking جلسه قبل مرتبط است.

محاسبه روی مقدارها

  • متغیر جمع را قبل از حلقه صفر می‌کنیم.
  • پیش از محاسبهٔ میانگین، حالت دیکشنری خالی را بررسی می‌کنیم.
scores = {"Python": 18, "Math": 16}
total = 0
for score in scores.values():
    total += score
if len(scores) > 0:
    print(total / len(scores))  # 17.0

قرار دادن total = 0 داخل حلقه باعث از دست رفتن جمع قبلی می‌شود. همین الگوی جمع‌زدن در پروژهٔ جلسه دهم تکرار خواهد شد.

انتساب و کپی

  • انتساب یک نام تازه برای همان دیکشنری می‌سازد.
  • copy یک دیکشنری جدید در سطح اول ایجاد می‌کند.
stock = {"pen": 10}
alias = stock
backup = stock.copy()
alias["pen"] = 8
print(stock["pen"])   # 8
print(backup["pen"])  # 10

این مثال مقادیر عددی ساده دارد. کپی سطحی را با مستقل بودن همهٔ ساختارهای داخلی اشتباه نگیرید.

محدودیت کپی سطحی

  • اگر مقدار یک کلید، List باشد، copy همان List داخلی را به اشتراک می‌گذارد.
first = {"skills": ["Python"]}
second = first.copy()
second["skills"].append("HTML")
print(first["skills"])
# ['Python', 'HTML']

قرار نیست در این جلسه deepcopy یا ماژول تازه تدریس شود. هدف شناخت محدودیت copy است. برای رکوردهای پروژه، هر بار دیکشنری تازه با مقادیر متنی و عددی می‌سازیم.

چند رکورد در یک List

  • هر Dictionary یک رکورد را توصیف می‌کند.
  • List چند رکورد را کنار هم نگه می‌دارد.
expenses = [
    {"title": "Book", "amount": 200000},
    {"title": "Bus", "amount": 50000},
]
print(expenses[0]["title"])  # Book

براکت اول در expenses[0] یک عضو List را انتخاب می‌کند. براکت دوم کلید title را از همان Dictionary می‌خواند. این دو دسترسی را جداگانه روی تخته نشان دهید.

7. مثال مبحث دوم

مثال دوم: جمع هزینه‌ها

  • ابتدا هر رکورد را می‌خوانیم، سپس مقدار amount را به جمع اضافه می‌کنیم.
expenses = [
    {"title": "Book", "amount": 200000},
    {"title": "Bus", "amount": 50000},
]
total = 0
for expense in expenses:
    total += expense["amount"]
print(total)  # 250000

این مثال پل ورود به پروژهٔ پایانی است. هنرجو یک هزینهٔ تازه اضافه کند و پیش از اجرا جمع جدید را بگوید.

8. نکات مهم

نکات مهم

  • عضویت با in به کلیدها مربوط است. برای مقدارها از values استفاده می‌کنیم.
  • دیکشنری ترتیب درج را نگه می‌دارد، ولی ساختاری مبتنی بر کلید است.
  • در زمان پیمایش مستقیم، تعداد اعضای همان دیکشنری را تغییر نمی‌دهیم.

تغییر مقدار یک کلید موجود با اضافه یا حذف کردن کلید متفاوت است. برای حذف چند کلید می‌توان ابتدا فهرست کلیدهای مورد نظر را ساخت و سپس حذف کرد.

9. خطاهای رایج

خطاهای رایج: دسترسی و نوع داده

  • KeyError: نام کلید اشتباه است یا کلید هنوز وجود ندارد.
  • TypeError: استفاده از List به‌عنوان کلید، یا جمع‌کردن متن با عدد.
  • کلیدهای name و Name متفاوت‌اند. نوع مقدارها را نیز بررسی کنید.

نمونهٔ خطادار را به‌صورت گفت‌وگو بررسی کنید: student["Name"] در پرونده‌ای با کلید name. سپس آن را اصلاح کنید. هدف تشخیص علت است، نه پنهان کردن همهٔ خطاها با get.

خطاهای رایج: تغییر و کپی

  • قرار دادن نتیجهٔ update در متغیر اصلی، آن را به None تبدیل می‌کند.
  • backup = original کپی نیست و تغییر از هر نام روی یک شیء اثر می‌گذارد.
  • copy فقط سطح اول را جدا می‌کند؛ دادهٔ تو در تو نیاز به توجه دارد.
