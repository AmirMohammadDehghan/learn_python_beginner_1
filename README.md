# learn_python_beginner_1

محتوای دورهٔ پایتون مقدماتی ۱، با حفظ ساختار پوشه‌ها و نام فایل‌های اصلی.

- پوشه‌های `ep_01` تا `ep_08`: فایل‌های جلسات دوره؛ کدهای نمونه در زیرپوشه‌های هر جلسه قرار دارند.
- پوشهٔ `ep_2_c`: نمونهٔ تکمیلی جلسهٔ دوم.
- فایل `python-self-study-book.html`: کتاب خودآموز دوره.
- آرشیوهای ZIP و ویدئوهای دوره در مسیر اصلی خود نگهداری می‌شوند.

فایل‌های PDF و پاورپوینت در این ریپازیتوری منتشر نشده‌اند. این فایل‌ها از نسخهٔ منتشرشدهٔ `pythonA1.zip` نیز حذف شده‌اند. پوشهٔ `ep_01` پس از حذف این فایل‌ها خالی است و با `.gitkeep` حفظ شده است.

## دریافت ویدئوها

ویدئوها با Git LFS نگهداری می‌شوند. برای دریافت کامل محتوا، پس از نصب Git و Git LFS، اجرا کنید:

```sh
git lfs install
git clone https://github.com/AmirMohammadDehghan/learn_python_beginner_1.git
cd learn_python_beginner_1
git lfs pull
```

کدهای نمونه با Python 3 اجرا می‌شوند. بعضی مثال‌ها برای دریافت ورودی از کاربر از `input()` استفاده می‌کنند.
